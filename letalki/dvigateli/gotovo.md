# «33» — выбор двигателя: готово, когда…

1. PDF собран, каждый слайд на своей странице, ничего не вылезает — проверено снимками страниц.
2. Есть схемы сравнения: стоимость, дальность и время, скорость и высота, температура, полезная нагрузка — у каждой подписаны значения.
3. Бензин и керосин идут отдельными вариантами на всех слайдах.
4. Каждая цифра — из справки, из расчёта `raschet.py` или из названного источника; оценки помечены.
5. Есть главное применение каждого варианта и итоговая рекомендация.
6. Сохранено, PDF лежит в «Файлах проекта».
