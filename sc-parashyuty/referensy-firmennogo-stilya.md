# SkyCenter — референсы фирменного стиля

Подготовка к гайдлайну SkyCenter и дизайну подарочных сертификатов.
Дата: 21.09.2026.

---

## 0. Отправная точка — текущий сайт skycenter.su

Данные сняты из кода и стилей сайта.

| Элемент | Сейчас |
|---|---|
| Основной цвет | голубой `#30CFFA` (93 употребления в CSS), близкий к нему `#13C8F9` |
| Вторичные | синий `#0075FF`, тёмный `#232323` / `#4A4A4A`, фон `#F8F8F8` |
| Акцент | красный `#DD3E3E`, розовый `#E82C5E` (единично, несистемно) |
| Заголовки | **Bebas Neue Bold** — узкий гротеск, только прописные |
| Текст | **Lato** (Regular, Light, Italic) |
| Тон | эмоциональный: «Место, где сбываются мечты», «море адреналина», плюс упор на безопасность |
| Фото | люди в свободном падении, аэродром, инструкторы, события выходных |
| Сертификаты | тандем в подарок, бесплатная доставка по Москве |

**Что уже хорошо:** «небесный» голубой как опорный цвет и связка Bebas Neue + Lato.
Кириллица есть в обоих, шрифты бесплатные.

**Чего не хватает:** нет знака, который работает отдельно от названия. Акцентные цвета
случайные: красный и розовый живут без правил. Нет графического приёма, по которому
материалы узнаются без логотипа. Сертификат пока просто товар, а не красивая вещь,
которую хочется подарить.

## 1. Skydive Dubai — парашютный спорт

**Почему он.** Самый известный дропзон в мире: прыжки над Пальмой Джумейра знает
каждый, кто хоть раз видел ролики о скайдайвинге. По продаже тандемов и сертификатов
для туристов это эталон отрасли.

**Устройство стиля**
- Логотип: плотный гротеск прописными `SKYDIVE DUBAI`, тёмно-серый с объёмом, и
  **красный росчерк-шлейф** над буквами. Он же читается как след падающего
  парашютиста, в росчерке силуэт под куполом.
- Цвета: графит или чёрный + один сигнальный красный. Всё остальное делают фото.
- Фото: одинаковый ракурс «с воздуха вниз на город» — это и есть их фирменный знак.

**Что взять для SkyCenter**
- **Один цвет-сигнал, а не три.** Голубой основной, акцент один и системный.
- **Фирменный вид сверху.** Пущино, Ока и поля с высоты 4000 м в каждом материале,
  чтобы виды SkyCenter узнавались так же, как Пальма у Дубая.
- Росчерк-траектория как графический элемент (на сертификате — линия прыжка).

## 2. Red Bull — экстремальный спорт и воздух

**Почему он.** Главный бренд экстрима в мире и спонсор неба: Red Bull Air Race,
прыжок Баумгартнера из стратосферы (Stratos), Red Bull Skydive Team, вингсьют-проекты.
Бренд продаёт не напиток, а ощущение «ты это сделал».

**Устройство стиля**
- Логотип: два быка и солнце; надпись — геометрический гротеск круга Futura
  (доработанные R и B).
- Цвета: красный `#FF0C49` (Pantone 192 C), жёлтый `#FFC800` (Pantone 7408 C),
  на упаковке синий с серебром.
- Сильные репортажные фото + крупная прописная типографика поверх. Каждое событие
  получает свой подбренд в общих правилах.

**Что взять для SkyCenter**
- **Фото первично, графика вторична.** Сертификат строится на одном сильном кадре
  свободного падения, текст лежит поверх в Bebas Neue.
- **Система подбрендов:** «Тандем», «AFF», «Вингсьют», «BigWay» — один каркас,
  у каждого свой цвет-метка. Отсюда линейка сертификатов.
- Тон «ты сделал это» вместо «купите прыжок».

## 3. Virgin Galactic — авиация и космос как впечатление

**Почему он.** Самый известный в мире стиль «продажи полёта». Билет Virgin Galactic —
по сути сертификат на впечатление за большие деньги, и оформлен он соответственно.
Автор айдентики — Филипп Старк вместе с GBH, шрифт Elevon — Dalton Maag. Проект
отмечен D&AD.

**Устройство стиля**
- Знак: **глаз-радужка**, где зрачок — солнечное затмение («рассвет нового»).
  Лаконичный символ, который работает без слов.
- Шрифт Elevon: плоские квадратные буквы, ретро-футуризм, собственная гарнитура.
- Цвета: глубокий космос (почти чёрный, тёмно-синий) + металлик/серебро,
  много воздуха, дорогие материалы.
- Всё, что получает клиент, сделано как предмет: билеты, конверты, нашивки.

**Что взять для SkyCenter**
- **Сертификат как билет на рейс.** Формат посадочного талона: пассажир, рейс
  `SC-4000`, высота, дата, «выход на посадку», отрывной корешок. Понятная метафора,
  приятно дарить.
- **Премиальная версия:** тёмный фон + серебряное или голубое тиснение, плотный картон,
  конверт — для дорогих пакетов (AFF, тандем с видео).
- Отдельный **знак-символ** SkyCenter, узнаваемый без надписи (купол, солнце,
  точка на горизонте).

## 4. GoPro — экстрим от первого лица

**Почему он.** Бренд, который сделал экстремальный спорт массовым контентом;
камера на шлеме — стандарт в парашютном спорте. Слоган «Be a Hero».

**Устройство стиля**
- Логотип: плотный техничный гротеск (на базе Neuropol, доработанная G), в брендинге
  шрифт Replica.
- Цвета: голубой `#00AEEF`, синий `#005DAC`, белый и чёрный. **Очень близко к
  голубому SkyCenter** — доказательство, что голубой в экстриме работает, если его
  держать строго.
- Контент: кадры от первого лица, герой — сам клиент, а не бренд.

**Что взять для SkyCenter**
- **Голубой оставить и дисциплинировать:** один голубой, один тёмный, белый; всё
  остальное — метки.
- **Герой — получатель подарка.** На сертификате крупно имя: «Анна, небо ждёт тебя».
- Связка сертификата с видео прыжка: QR-код «Посмотри, как это будет».

## 5. Сводка: направление для SkyCenter

| | Skydive Dubai | Red Bull | Virgin Galactic | GoPro |
|---|---|---|---|---|
| Главный приём | фирменный вид сверху | фото + крупный шрифт | предмет-билет, премиум | герой — клиент |
| Цвет | графит + красный | красный + жёлтый | тёмный + металлик | голубой + синий |
| Берём | один акцент, вид Оки | подбренды дисциплин | формат посадочного талона | имя крупно, QR на видео |

**Предлагаемая основа гайдлайна**
1. **Цвета:** голубой `#30CFFA` (небо) + глубокий тёмно-синий, например
   `#0B1B2B` (высота, премиум) + белый. **Один акцент** — сигнальный оранжевый
   купола, например `#FF6A1A`; красный и розовый с сайта убираем.
   Значения предварительные, уточним с контрастом.
2. **Шрифты:** оставить Bebas Neue (заголовки) + Lato (текст) — кириллица есть,
   преемственность с сайтом.
3. **Знак:** новый символ, работающий без надписи (купол / солнце над горизонтом).
4. **Графический приём:** линия траектории прыжка + высотная шкала (4000 → 0 м).
5. **Сертификаты — линейка «посадочный талон»:** общий каркас, цвет-метка
   дисциплины, фото с высоты, имя получателя, QR на видео, отрывной корешок;
   премиум-версия на тёмном фоне с тиснением.

**Следующий шаг:** 2–3 эскиза сертификата (светлый, тёмный премиум, посадочный талон)
в HTML/SVG для выбора направления.
