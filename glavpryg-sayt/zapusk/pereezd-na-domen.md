# Главпрыг: переезд сайта на главпрыг.рф

План от 22 октября 2026 г. Сейчас сайт работает по адресу mokeevasky.ru/glavpryg, а на главпрыг.рф стоит старый сайт на Tilda. После переезда главпрыг.рф показывает новый сайт, старые адреса ведут на новые страницы, позиции в поиске сохраняются.

Домен для сервера записывается латиницей (punycode): **главпрыг.рф = xn--80aebc1b0ah2g.xn--p1ai**.

## Что подготовлено заранее

- Сайт не привязан к адресу: ссылки, письма, карта сайта, превью и админка берут адрес из одной настройки. Переезд — это смена одной строки и настройка сервера, переделывать код не нужно.
- Готов конфиг сервера для нового домена: `deploy/nginx-glavpryg-domen.conf`. Синтаксис проверен nginx.
- В конфиге есть таблица перенаправлений со старых адресов Tilda на новые страницы (ниже). **Сверьте её**: соответствие подобрано по названиям страниц, а не по содержанию.

| Старый адрес (Tilda) | Новая страница |
|---|---|
| /tandem, /phototandem, /photo | /services/tandem — тандем |
| /prig | /services/samostoyatelnyy — самостоятельный прыжок |
| /education | /services/obuchenie — обучение |
| /sport, /arbalet | /services/sportivnye — спортивные прыжки |
| /fly | /prices — цены |
| /sert1 | /certificate — сертификаты |
| /sert-form | /certificate/order — заказ сертификата |
| /news | /blog |
| /contact | /contacts |
| /fitback, /more | /about — о нас |
| /fun, /page….html | главная |
| /docs, /conf | /legal/privacy — политика |
| /user | /legal/terms — соглашение |

## Порядок переезда

### За неделю

1. **Домен.** Проверить, у кого регистратор главпрыг.рф и есть ли у вас доступ, и что домен оплачен минимум на год вперёд.
2. **DNS.** Зона домена — в аккаунте Cloudflare заказчика, режим «только DNS» (серое облако), как решено ранее. Снизить TTL записей домена до 300 секунд, чтобы переключение прошло быстро.
3. **Почта.** Если на домене есть рабочая почта (MX-записи), их не трогать. Для писем сайта завести SPF, DKIM и DMARC на новый домен по записке `pochta.md`.
4. **Таблица перенаправлений** сверена (выше).

### День переезда

Все шаги выполняет программист на сервере. Сайт не останавливается ни на минуту.

1. Резервная копия: `deploy/rezerv.sh`.
2. В DNS записи `@` и `www` главпрыг.рф направить на IP сервера 46.8.178.196 (тип A).
3. Получить сертификат HTTPS: `certbot certonly --webroot -w /var/www/certbot -d xn--80aebc1b0ah2g.xn--p1ai -d www.xn--80aebc1b0ah2g.xn--p1ai`. Для этого сначала временно включить только HTTP-блок из конфига.
4. Положить `deploy/nginx-glavpryg-domen.conf` в `/etc/nginx/sites-available/glavpryg-domen`, включить, затем `nginx -t` и `systemctl reload nginx`.
5. В `/var/www/glavpryg/.env`:
   - `APP_URL=https://xn--80aebc1b0ah2g.xn--p1ai`
   - `ASSET_URL=https://xn--80aebc1b0ah2g.xn--p1ai`
   - `MAIL_FROM_ADDRESS` — ящик на новом домене, когда его почта настроена (п. 3 выше)

   Затем выполнить `php artisan config:clear` и `php artisan view:clear`.
6. В `public/robots.txt` поменять строку `Sitemap:` на `https://xn--80aebc1b0ah2g.xn--p1ai/sitemap.xml`.
7. Проверка: `bash tests/check-glavpryg.sh https://xn--80aebc1b0ah2g.xn--p1ai` и `tests/check-zapusk.py https://xn--80aebc1b0ah2g.xn--p1ai`. Руками: вход в админку, загрузка картинки в админке, заявка с сайта, письмо о заявке.
8. Проверить перенаправления: 2–3 старых адреса Tilda открываются на новых страницах, `www.` уводит на адрес без www, `http://` уводит на `https://`.
9. Старый адрес закрыть: заменить `/etc/nginx/snippets/glavpryg.conf` на перенаправление (готовые строки — в конце `nginx-glavpryg-domen.conf`). После этого mokeevasky.ru/glavpryg/… ведёт на те же страницы главпрыг.рф.

### Сразу после

1. **Яндекс Вебмастер:** добавить сайт `https://главпрыг.рф`, внести код подтверждения в админке («Настройки сайта» → «Метрика и поиск»), отправить карту сайта. Если старый сайт на Tilda уже был добавлен, в разделе «Переезд сайта» ничего указывать не нужно: домен тот же.
2. **Google Search Console:** то же самое. Подтверждение через мета-тег из админки.
3. **Яндекс Метрика:** в настройках счётчика указать адрес главпрыг.рф. Номер счётчика вносится в админке, и цели начинают работать.
4. **Яндекс Бизнес, 2ГИС, Google:** поменять ссылку на сайт в карточке организации.
5. **Соцсети и реклама:** поменять ссылки в профилях ВКонтакте, Telegram и в рекламных объявлениях.
6. **Tilda:** отключить домен в настройках проекта Tilda, но сам проект держать ещё месяц как запасной вариант.
7. **Эквайринг:** подавать заявку в ВТБ уже с новым доменом (см. `podgotovka-k-zapusku.md`, раздел 3).

### Через 2–4 недели

- Вебмастер: старые адреса Tilda должны уйти из поиска, а новые страницы появиться. Если какой-то старый адрес даёт 404, допишите его в таблицу перенаправлений.
- Метрика: заявки идут, цели считаются.

## Если что-то пошло не так

Откат в течение пяти минут. Вернуть DNS-записи главпрыг.рф на Tilda и вернуть прежние `APP_URL` и `ASSET_URL` в `.env`. Сайт по адресу mokeevasky.ru/glavpryg продолжает работать, пока не выполнен шаг 9 дня переезда.
