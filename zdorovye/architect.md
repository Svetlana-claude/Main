# «Здоровье семьи» — устройство

Закрытый сайт на `https://mokeevasky.ru/zdorovye/`, ставится на телефон как
приложение («На экран Домой»). Шаг 1 из трёх (см. `gotovo.md`): странички,
анализы, прививки, болезни, доступы, копии. Шаг 2 — визиты и напоминания,
шаг 3 — вопросы с поиском по PubMed.

## Где что

```
zdorovye/
├── app/
│   ├── main.py        приложение, заголовки безопасности, описание приложения, работник
│   ├── config.py      настройки; ключ — ~/.config/zdorovye/zdorovye.env (600)
│   ├── db.py          SQLite ~/.local/share/zdorovye/zdorovye.db (600), схема
│   ├── security.py    пароли (argon2), сессии, подбор, код с телефона (как в webui2)
│   ├── web.py         общие помощники, даты по Москве, ПРАВА на странички
│   ├── auth.py        первая настройка, вход, приглашения, доступы
│   ├── family.py      главная, страничка, болезни, прививки
│   ├── labs.py        бланки: загрузка, разбор Claude, проверка, графики
│   ├── kopii.py       блок «Копии» и разовое скачивание ключа
│   ├── organs.py      фигурка: органы, цвет по правилам, оценка Claude
│   ├── templates/     страницы
│   └── static/        оформление, app.js, sw.js, значки (сердце с «М»)
├── tools/prepare.py   файл настроек, база, разовая ссылка первой настройки
├── tools/kopiya.py    ключ, ночная копия, проверка и восстановление копии
├── deploy/            служба zdorovye (порт 8003) и правила nginx
└── tests/             pytest (подставной Claude) и check_browser.py
```

Данные: `~/.local/share/zdorovye/` — база и `files/` (бланки, случайные имена).
В образ сервера данные **не входят** нарочно: они только в своей зашифрованной
копии. В образ входят настройки (`~/.config/zdorovye`), открытая половина ключа
копий (`~/.local/share/zdorovye-kopii-gnupg`) и служба.

## Входы и права

- **Светлана** (`role=owner`, логин `Svetlana`) — пароль и код с телефона
  (своя строка «Здоровье» в приложении кодов). Видит и правит всех.
- **Остальные** (`role=member`) — входят по разовой ссылке-приглашению
  (`/join/<токен>`, неделя, в базе только хеш), придумывают логин и пароль.
  Видят и правят только свою страничку.
- **Близкие.** Тот, чью страничку завела Светлана (`members.added_by IS NULL`),
  может добавить до 5 своих (`config.ADD_LIMIT`, `members.added_by` = его
  страничка), видит и правит их, удаляет, выдаёт им приглашение. Их имена —
  вкладками в шапке (на телефоне — вторым рядом). Близкие сами добавлять не
  могут. Светлана видит у карточки «Добавил(а)». Права — `web.can_edit` /
  `can_add` / `added_by_me`.
- **Чужая страничка** — запрос «Попросить доступ» → у Светланы на «Доступах»
  «Принять» / «Отклонить», выданный — «Завершить». Доступ — только смотреть.
- Все проверки — в `web.member_for`: нет прав — 404 (не видно, есть ли такая).
- Формы: защитный знак сессии + проверка Origin. `Referrer-Policy: same-origin`
  (с `no-referrer` браузер шлёт `Origin: null`, и формы не проходят).
- Подбор: 5 неудач с адреса за 15 минут — блок; плюс зона `login` в nginx на
  вход, приглашения и настройку.

## Анализы

Фото ужимается до 2400 px (JPEG, поворот по EXIF, HEIC с айфона читается), PDF —
как есть, до 25 МБ. Разбор — `claude -p` (sonnet), только чтение, в пустой
временной папке с копией бланка, по одному за раз. Ответ — JSON с показателями;
разобранное ждёт проверки (`state=review`), в базу показатели попадают только
после «Сохранить». График — SVG с сервера по ключу показателя (`db.key_of`),
полоса нормы — по последнему бланку. Каждый разбор тратит немного лимита Claude.

## Фигурка «Организм»

Свой рисунок (`templates/_body.html`, SVG) по мотивам картинки Светланы с
фотобанка — саму картинку не берём: права у фотобанка, и её не перекрасить по
органам. 12 органов (`organs.ORGANS`), у каждого слова для показателей и болезней;
показатель — к первому органу, чьё слово нашлось (порядок важен: «…в моче» —
почки). Цвет — `organs.state_of`: розовый — данные есть и в норме, жёлтый — вне
нормы / болезнь в последние 14 дней / хроническое, тёмно-красный — далеко за
нормой (больше половины ширины нормы; при одной границе — в 1,5 раза) или так
оценил Claude; бледный — данных нет; «?» — нет данных или у Claude вопросы.
Наведение — подсказка, щелчок или касание — блок органа (анализы, болезни,
вопросы, что сделать). «Оценить» — один запуск Claude без инструментов по всем
данным человека (`organs.snapshot`), ответ — в `assessments`; отпечаток данных
не совпал — «оценку стоит обновить». Уровень Claude красит орган только при
наличии по нему данных.

## Копии

Шифр открытым ключом gpg: на сервере только открытая половина, закрытая
(`~/.local/share/zdorovye/klyuch-kopiy.asc`) лежит до тех пор, пока Светлана не
скачает её на «Доступах» и не подтвердит — тогда удаляется. Ночью (cron, 04:45
по Москве) — `tools/kopiya.py sdelat`: снимок базы + бланки → tar → gpg →
`~/backups/zdorovye/` (14 последних) и Selectel S3 `zdorovye-kopii/` (14).
Журнал — `~/backups/zdorovye/kopiya.log`.

Восстановление: `tools/kopiya.py vosstanovit КЛЮЧ КОПИЯ ПАПКА`, затем
`zdorovye.db` и `files/` — в `~/.local/share/zdorovye/`, перезапуск службы.

## Проверки

  защита форм, приглашения, доступы, странички, разбор, графики, копии.
- `exchange/pwenv/bin/python zdorovye/tests/check_browser.py` — всё то же в
  браузере на компьютере и телефоне, снимки в `tests/shots/`.
- `tests/obrazec-blanka.png` — выдуманный бланк для проверки настоящего разбора.
