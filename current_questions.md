## 1. Начинать ли этап 0

**Вопрос:** можно приступать к установке PostgreSQL 16, nginx и каркаса приложения?

**Почему возник:** блокеры сняты — беспарольный `sudo` включён, способ интеграции выбран
(вариант А, Claude Code в неинтерактивном режиме). Спрашиваю потому, что этап 0 открывает
наружу новый порт и ставит системные пакеты, а в разделе 4 файла `exchange/ant.md`
(пересмотр стека: PostgreSQL вместо MariaDB, Claude Code вместо Messages API) строка
ответа осталась пустой — прямого подтверждения правок стека нет.

**Что предлагается:** считаю молчание за отсутствие возражений. По вашему слову начинаю
этап 0; если в пересмотренном стеке что-то не устраивает — скажите до начала установки.
