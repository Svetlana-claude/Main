## 1. URL репозитория на GitHub

**Вопрос:** какой адрес у репозитория? Нужен формат
`git@github.com:<владелец>/<репозиторий>.git`.

**Почему возник:** git инициализирован локально, remote не задан, первый push сделать
некуда. Правило 6 требует пушить после завершения задания — выполнить его пока нельзя.

**Что предлагается:** добавить публичный ключ из `exchange/git.txt` на GitHub
(deploy key с правом записи либо ключ аккаунта), затем сообщить URL — remote и push
настрою сам.
