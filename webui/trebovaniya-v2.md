# Рабочее место v2 — требования

Редакция 1 от 27.10.2026, черновик до ответов заказчика.
Переделка `webui` с нуля. Движок прежний — Claude Code CLI в режиме `-p`
(подписка, `CLAUDE.md`, скиллы и память подхватываются сами).

## 1. Цель

Один экран, на котором ставится задача, виден ответ и забирается результат.
Всё, что не помогает этому, — убирается или прячется за одно нажатие.

## 2. Принципы

1. **Один главный экран.** Список разговоров слева, разговор справа, поле
   ввода внизу. Прочие страницы — исключение, а не навигация.
2. **Ноль лишних нажатий.** Новая задача — одно нажатие или `Ctrl+K`.
   Отправка — `Enter`. Файл — перетащить в поле ввода.
3. **Ничего, что не используется каждую неделю,** на главном экране нет.
   Редкое (настройки, вход Claude, второй фактор) — в одном меню.
4. **Скорость.** Первая отрисовка < 300 мс, страница < 100 КБ без картинок,
   никаких сборщиков и библиотек на клиенте.
5. **Тишина.** Без бейджей, счётчиков, анимаций и цветных плашек, кроме
   состояния «идёт ответ» и ошибок.
6. **Результат — сразу.** Созданные файлы (PDF, картинки, архивы) показываются
   прямо в ответе ссылкой «открыть / скачать».

## 3. Состав (минимум)

| Есть | Нет |
|---|---|
| Вход: пароль + код TOTP | регистрация, роли, несколько пользователей |
| Разговоры по проектам, поиск по ним | отдельные «чатики» и «темы» — одна сущность |
| Поток ответа в реальном времени, кнопка «Стоп» | показ каждого шага инструментов (свёрнут) |
| Вложение файлов в сообщение | отдельная вкладка «Загрузка» |
| Файлы проекта: список, открыть, скачать | — |
| Расход: одна строка под разговором | графики, панели метрик |
| Настройки: модель, потолок, вход Claude, TOTP | — |

## 4. Нефункциональные требования

* Стек прежний: FastAPI, Jinja2, PostgreSQL, ванильный JS, свой CSS.
* Адаптивность: 1440 px и 390 px, телефон — полноценный клиент.
* Доступность: фокус с клавиатуры, контраст AA, все действия с клавиатуры.
* Безопасность — не хуже текущей: argon2id, TOTP, серверные сессии,
  явные запреты инструментов и путей (см. `architect.md`).
* Данные текущей базы переносятся: разговоры, сообщения, файлы.
