# Рабочее место v2 — требования

Редакция 2 от 27.10.2026, по ответам заказчика.
Переделка `webui` с нуля. Движок прежний — Claude Code CLI в режиме `-p`
(подписка, `CLAUDE.md`, скиллы и память подхватываются сами).

## 1. Цель

Один экран, на котором ставится задача, виден ответ и забирается результат.
Всё, что не помогает этому, — убирается или прячется за одно нажатие.

## 2. Принципы

1. **Один главный экран.** Открывается **последний разговор**. Список разговоров
   слева (на телефоне — по кнопке), разговор справа, поле ввода внизу.
2. **Телефон — полноценный клиент.** Главный экран проектируется сперва под
   390 px, затем растягивается на 1440 px.
3. **Ноль лишних нажатий.** Новая задача — одно нажатие. Отправка — `Enter`
   (на телефоне — кнопка). Файл — перетащить или выбрать в поле ввода.
4. **Тишина.** Ход работы Claude (чтение файлов, команды) **скрыт**: видно
   только «идёт ответ» и сам ответ. Без бейджей, счётчиков и анимаций.
5. **Светлое оформление**, спокойная типографика, много воздуха.
6. **Скорость.** Первая отрисовка < 300 мс, страница < 100 КБ без картинок,
   никаких сборщиков и библиотек на клиенте.

## 3. Состав

| Остаётся | Убирается |
|---|---|
| Вход: пароль + код TOTP, вход Claude | расход токенов |
| Чатики и темы проектов — **раздельно**, как сейчас | метрики сервера и график |
| Поток ответа, кнопка «Стоп» | показ хода работы Claude |
| Файлы проекта — **в отдельном окне** | выбор модели и потолка контекста |
| «Картинки», поиск, журнал | совместимость с Телеграм-ботом |
| «Безопасность», VPN, настройки | |

Редкие разделы («Картинки», журнал, «Безопасность», VPN, настройки) — в одном
меню, не на главном экране.

## 4. Запуск

* Новый сайт работает **рядом со старым** по адресу `https://svetiksky.ru`;
  старый остаётся на `mokeevasky.ru/Claude` до переключения.
* Оба смотрят в **одну базу** — разговоры и файлы видны в обоих, перенос
  данных не нужен.
* Свой каталог проекта `webui2/`, своя служба и свой порт.

## 5. Нефункциональные требования

* Стек: FastAPI, Jinja2, PostgreSQL, ванильный JS, свой CSS.
* Доступность: фокус с клавиатуры, контраст AA.
* Безопасность — не хуже текущей: argon2id, TOTP, серверные сессии,
  явные запреты инструментов и путей (см. `architect.md`).

## 6. Порядок работ

1. Каркас `webui2/`: вход (пароль + TOTP), общая база, служба.
2. Главный экран: последний разговор, список, отправка, поток, «Стоп».
3. Темы проектов и окно «Файлы проекта».
4. Меню: поиск, «Картинки», журнал, «Безопасность», VPN, настройки.
5. Домен svetiksky.ru, TLS, проверка на телефоне и компьютере.
